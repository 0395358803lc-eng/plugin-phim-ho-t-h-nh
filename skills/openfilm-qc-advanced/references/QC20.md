# N14 — QC20 master acceptance checklist (derived from research report)

For each checkpoint store `PASS|FAIL|BLOCKED`, actual path, command, log/time and reviewer. `BLOCKED` is not `PASS`. Do not perform destructive file operations; a release gate requires actual media and human listening when relevant.

| No. | Check | Minimum proof |
|---:|---|---|
| 01 | Script locked | approved screenplay revision/hash |
| 02 | Shot timing | FilmData integer start/end frame |
| 03 | Dialogue WAV complete | all referenced files actually exist |
| 04 | Real WAV durations | FFprobe report per WAV and updated FilmData |
| 05 | State independent of frame order | random seek regression at same frame |
| 06 | 3D transform derived from frame | source review + screenshot comparison |
| 07 | GSAP paused+seek | source review + random seek test |
| 08 | Vietnamese glyphs | screenshot of diacritics on target resolution |
| 09 | Dialogue unclipped | waveform/peak + actual listening |
| 10 | Music rights | verified license/provenance |
| 11 | SFX rights | verified license/provenance |
| 12 | Captions aligned | SRT/VTT cue evidence vs WAV timeline |
| 13 | Video dimensions | FFprobe master resolution vs profile |
| 14 | Video FPS | FFprobe avg frame rate vs target |
| 15 | Encoders | FFprobe video/audio codec H264/AAC when target requires |
| 16 | First/last frames valid | checked images of first/last frame |
| 17 | 3D textures/models present | asset manifest + rendered spot check |
| 18 | Full playback | actual full-length video watched at least once |
| 19 | Stream anomalies | FFprobe JSON + error scan |
| 20 | Sources retained | source, WAV, FilmData, SRT and master paths recorded |

**Additional**: FFmpeg ebur128/loudness, speech/music ducking, blank/black flash or clipping, camera motion, exact half-open shot boundary, path safety, license checks. Report issues with severity; STOP master release while any required FAIL or BLOCKED remains.

Smoke acceptance: a *real* five-second film with frames/video + audio and metadata check. Source files, empty placeholder WAV or logs alone do not count as a smoke pass.
